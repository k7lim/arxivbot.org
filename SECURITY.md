# Security Policy

If you find a security problem in ArxivBot or arxivbot.org, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/k7lim/arxivbot.org/security/advisories/new)
instead of opening a public issue.

Include what you found, how to reproduce it, and what impact you think it has.
You should hear back within a week.

Please don't run load tests or automated scanners against arxivbot.org; it runs on a
small free-tier LLM quota shared by all users.
